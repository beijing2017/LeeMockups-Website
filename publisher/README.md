# LeeMockups Publisher V1

This is a local preparation tool inside the existing website repository. It does not deploy the site, upload to Cloudflare, or publish on Etsy.

1. Install the website dependencies with `npm ci` and install FFmpeg, or set `FFMPEG_PATH` to the FFmpeg executable.
2. Set `ASSET_BASE_URL` to the HTTPS public URL of the LeeMockups Cloudflare R2 asset domain (without a trailing slash).
3. Run `npm run publisher` and open `http://127.0.0.1:4177`.
4. Select the already reserved `LM-VM-MUG-001`, or reserve the next category SKU. A reserved SKU remains in `data/products.json` forever, including archived products.
5. Review the visual observations and generated copy. The content fallback uses product fields and manually confirmed observations; no image-analysis API or key is required. The fixed delivery, use, and digital-item paragraphs are generated by the template.
6. Enter matching `SKU.mockup` and `SKU.mp4` paths plus a different-artwork effect image. The video must be 2000×2000 and 8–15 seconds. Prepare generates `publisher-output/SKU/web` and `publisher-output/SKU/etsy-package`.
7. Upload the two web files to the R2 keys in `upload-manifest.json`, then confirm the final source, asset upload, and Etsy URL in the workbench. Set `PUBLISHED` only after these checks, commit the registry, and deploy the website through its existing workflow.

The website uses only `PUBLISHED` products and resolves their web asset paths through `ASSET_BASE_URL` at build time. The first SKU is intentionally `DRAFT`; the previously supplied video is a test and must not be marked final. The Etsy package contains a 1000×1000 JPG main image, 1000×1000 MP4, an alternate effect JPG, two fixed 1000×1000 instruction PNGs, the `.mockup` file, and a listing text draft. Review all images and copy before using them on Etsy.

This V1 deliberately leaves Cloudflare upload as a verified manual step because the existing website repository has no R2 credentials or upload configuration. It also has no Etsy API integration or product detail pages.
